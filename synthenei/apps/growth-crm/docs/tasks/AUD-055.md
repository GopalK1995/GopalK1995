# AUD-055 Canonical DataTable (DataGrid)

Status: component built and proven on two tables; the rest is migration work.

## What was built
`src/components/ui/data-grid.tsx` exports `DataGrid` (the canonical table), `safeCount`, and the types `DataGridColumn`, `DataGridProps`, `DataGridPagination`, `RowAction`.
Tests: `src/components/ui/__tests__/data-grid.test.tsx` (17 cases: structure, roles, sort and aria-sort, selection and live region, client/server/keyset paging, no NaN, column chooser, row actions, roving keyboard).

Features: typed generic columns; sortable headers with `aria-sort` (client sort cycles asc, desc, none and keeps empty values last; server sort via `sort` plus `onSortChange` or `sortHref`); optional selection with tri-state select-all for the visible page, controlled or uncontrolled, bulk-action slot, polite live region "n of m selected"; pagination modes client, server (page, total) and keyset (prev/next, no total); sticky header (`maxHeight`); `density`; column chooser (`columnControl`); row actions menu (`rowActions`); loading skeleton, error state, honest empty slot; focusable named scroll region with visible focus ring; roving tabindex over rows (arrows, Home, End, Space selects, Enter activates); `responsive="stack"` turns rows into labelled cards below md using CSS only, so rows exist once in the DOM (fixes COMP-029 for migrated tables).

## Migrated (proof)
