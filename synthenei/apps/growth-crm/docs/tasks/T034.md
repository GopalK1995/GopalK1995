# T034: CSV / Excel import and export (connector #0)

Built
- `src/lib/import/**`: limits (5 MB, 10,000 rows, 60 columns), E.164 phone normaliser, formula-safe CSV writer, papaparse and exceljs parsing, header auto-mapper (field_defs and saved `importMappings`), planner (new, duplicate, invalid), dedupe (email, E.164 phone, account name+city, repeats inside the file), error-report CSV, export with PII masks, storage path guard, batched writer, demo sample.
- `src/lib/jobs/handlers/import.ts` (`import.run` on the `import` queue, registered in handlers/index.ts): download from the private `imports` bucket, parse, plan, batched write, progress on `import_jobs`, error report upload.
- `/import` page: wizard (file, columns, review, progress), history, export panel. The leads import dialog now wraps the same wizard.
- Server actions (`src/app/(app)/import/actions.ts`): permission catalogue only (`leads.import` plus the object's write permission; `leads.export` plus read, support-blocked), audit events `import.started` and `export.csv`, tenant-checked paths, signed upload URL, demo branch that saves nothing.
- i18n namespace `imports`, English only (Tamil falls back to English; no `ta` file so the shared review test is untouched).
- Unit tests: phone, mapper, dedupe, planner, csv-guard, parse, report, export, storage paths. Cypress: import/leads-csv, xlsx-accounts, dedupe-merge, error-report, export/list-masked (written, not run).
