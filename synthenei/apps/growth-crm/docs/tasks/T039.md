Done:
- Three connectors under src/lib/connectors/google/{ga4,ads,sheets,shared}/**, registered in connectors/all.ts: `ga4`, `google-ads`, `google-sheets`. OAuth 2 (one Google client, env names only, PKCE, offline access + consent so a refresh token always comes back) through the connector core; tokens in the Vault. Read-only scopes (`analytics.readonly`, `spreadsheets.readonly`; Ads has only `adwords`).
- GA4: `selectGa4Property` (from Admin API accountSummaries; the id must be one the user can read), daily stream: `runReport` with offset paging, 7 dimensions (date, channel group, source / medium, device, city, landing page, campaign) and 6 metrics (sessions, engaged sessions, total users, new users, engagement duration, key events) into `ga4_daily`. 90-day backfill, then a 3-day re-read from 05:30 IST (hourly slot, the step decides). The window is replaced, not appended. Campaign column and workspace-safe key need the optional SQL (falls back without it). "(not set)" -> empty, channel falls back to Unassigned, nulls are never zeros, `(other)` row and data thresholds are flagged in the run sample.
- Google Ads: `selectAdsCustomer` (client accounts, managers expanded to their enabled clients, login-customer-id kept), daily GAQL over `googleAds:search` with page tokens into `campaign_daily_metrics` (campaigns created in `campaigns`, channel google_ads), cost micros (int64 string, BigInt exact) -> currency units -> INR with the tenant's `fx_to_inr` (INR passes; another currency without a rate is rejected, never guessed), conversions rounded to a whole count. 30-day backfill, 7-day re-read from 06:00 IST. Developer token from an env name; the gate "Needs Google Ads developer token (basic access)" is the connector gate, and an unapproved-token answer from Google becomes a CredentialError with that text.
- Google Sheets import: `listSheetTabs`, `previewSheet` (headers, 5 sample rows, suggested mapping, plan: new / duplicate / invalid), `startSheetImport` (saved configuration with a fresh nonce, audited). The `import` stream reads the range, maps columns (saved mapping, else the field-mapping editor rows of object `Row`, else header auto-map), plans with the T034 planner (email, E.164 phone, account name + city, repeats in the sheet) and writes with the T034 writer (skip or merge). One-time import = a new nonce; optional daily re-sync never doubles a record.
- Tokens: refresh through the core (`ConnectorDef.refresh`): a dead grant (`invalid_grant` and kin) is a CredentialError -> needs_attention with a readable reason, never silent; 5xx / 429 / network are transient (job retries, connection not flagged). Quota: 429 / `rateLimitExceeded` (also when Google sends it as a 403) / 5xx retry with exponential backoff + jitter, Retry-After honoured; a real 403 (permission) or 401 is not retried.
- Tenant isolation: connection lookups check tenant and workspace; every store call is scoped by tenant_id and workspace_id; the sheet planner dedupes inside the workspace only. Audit events: `connector.connected|disconnected|reconnected` (core), `ga4.property_selected`, `google_ads.customer_selected`, `google_sheets.import_requested` (audit or nothing; details carry ids and counts, no cell values).
