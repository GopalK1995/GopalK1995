Done:
- Connector `meta-ads` (src/lib/connectors/meta-ads/**, registered in connectors/all.ts). OAuth (Facebook Login, scopes in docs/META-PERMISSIONS.md) through the connector core; tokens in the Vault. `selectMetaAssets` (server action target) picks Page, linked Instagram account and ad account from what Meta says the user manages, long-lives the user token, takes the page token, subscribes the Page (leadgen, plus messages when Instagram is linked), stores the webhook secret bundle (app secret + verify token) and audits. `listMetaAssets` returns names/ids only.
- Lead Ads: signed webhook (X-Hub-Signature-256, T023 receiver, scheme meta) -> lead fetched by leadgen_id -> form answers mapped through the tenant field map (defaults for Meta's standard questions, object `Lead`) -> lead created or matched by E.164 phone / lower email. New lead: source `meta`, first/last touch channel meta, utm, campaign text and campaign link (campaign created from Meta's id when unknown). Existing person: first touch and source kept, only last touch moves. Idempotent by leadgen id (external link). Consent only from the form: a `consent_<purpose>` answer of yes or a ticked disclaimer checkbox per connection `consent_rules`; written once per leadgen id (consent_log, captured_via integration) with `consent.changed`.
- Instagram DMs: messaging webhook -> lead (by IGSID) / conversation (channel instagram) / message, dedupe by mid, echoes ignored, last_inbound_at forward only. Outbound dispatcher (every 15 min) sends queued replies only inside the 24 h window (no templates on Instagram), 1000-byte cap, throttle, vendor codes kept; a closed window is `failed` with `window_closed`.
- Ads Insights: stream `insights` (hourly slot, runs once per IST day after 06:00) -> campaign_daily_metrics upserted by (campaign, day): 30-day backfill, trailing 7-day re-read, resumable pages, spend to paise, INR only unless the tenant sets `fx_to_inr` (else the row is rejected, never guessed), lead/reaction/comment/share counts. Sandbox rows get source `mock` and synthetic campaigns.
- Tokens: `refresh` exchanges the long-lived user token (fb_exchange_token) via the core refresh path; dead token = CredentialError = needs_attention; stream `health` (daily) checks debug_token (valid, days left, missing scopes). Rate limits: Meta throttle codes (4, 17, 32, 613, 80000-80014) reported as HTTP 400 are retried with backoff; appsecret_proof on every call.
- Tenant isolation: events are processed only for the page / Instagram id in THIS connection's credentials; `meta_assets` makes page and Instagram ids unique platform-wide (SQL in backlog); selection of a page owned by another live connection is refused.
- Sandbox / showcase: mock gateway (token `meta-mock-token`, or APP_ENV=demo without credentials), no network, refused in production. `META_GRAPH_API_BASE` points the client at a stub.
- Strings: namespace `metaAds` (en, ta draft) registered in src/i18n/registry.ts; `meta-ads.sandbox` in integrations.json. Env names in .env.example, no values.
